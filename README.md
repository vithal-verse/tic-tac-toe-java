# Tic Tac Toe

A simple two-player Tic Tac Toe game made with Java Swing.

## Run on Windows

1. Install Java (JDK 17 or newer).
2. Open Command Prompt in this folder.
3. Compile the game:

```text
javac TicTacToe.java
```

4. Start the game:

```text
java TicTacToe
```

You can also double-click `run-tictactoe.bat` on Windows. It starts the included `TicTacToe.jar` file.

For an easy download, use `TicTacToe-Windows.zip`, which contains both files.

The JAR requires Java to be installed on the laptop.

Player X starts. Click **New Game** to play again.
